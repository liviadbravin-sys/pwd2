# Lista de Tarefas Interativa

## Descrição do Projeto

Este projeto consiste no desenvolvimento de uma aplicação web de Lista de Tarefas Interativa (To-Do List), criada para facilitar a organização das atividades do dia a dia.

A aplicação permite adicionar e remover tarefas, marcar tarefas como concluídas e filtrar as atividades por status, podendo visualizar todas as tarefas, apenas as pendentes ou somente as concluídas.

Os dados são salvos automaticamente no armazenamento local do navegador (localStorage), permitindo que as tarefas continuem salvas mesmo após atualizar a página ou fechar o navegador.

O projeto utiliza as seguintes tecnologias:

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização da interface e adaptação para diferentes tamanhos de tela.
- **JavaScript:** implementação das funcionalidades e da interatividade.
